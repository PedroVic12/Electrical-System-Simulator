# Simulador de Redes Elétricas - IEEE cases
---

1) instale as depedencias

```py
pip install -t requeriments.txt
```


2) Execute o aplicativo desktop

```py
python simulator_darkmode_desktop.py
```


3) Se quiser, faça um arquivo executavel do projeto

```py
pip install pyinstaller
```

```sh
pyinstaller --onefile --windowed simulator_darkmode_desktop.py
```
